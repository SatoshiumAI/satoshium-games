Welcome to the documentation hub for **Satoshium Games**, the interactive simulation layer of the Satoshium platform ecosystem.

# 🎮 Purpose of This Repository

Satoshium Games provides **explainable simulation environments** that demonstrate how signal-aware agents behave under structured coordination rules.

These modules function as:

- learning tools
- research demonstrations
- architectural prototypes
- coordination experiments
- trust-signal visualization environments

Each game is designed to be transparent, inspectable, and reproducible.
